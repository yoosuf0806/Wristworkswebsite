# The Psychology of Food — Presentation

A 5-slide talk on why we choose the food we choose: visual psychology, menu
wording, memory & emotion, and how it all adds up.

**Deliverable:** `Psychology_of_Food_Choices.pptx` (16:9, speaker notes on every slide)

Presenter: Nooha Iflal

## Slides
1. **What Would You Choose?** — the 5-second hook (burger / pizza / salad / cake)
2. **Your Eyes Choose First** — plain vs. styled burger; See → Expect → Choose
3. **The Menu Is Playing Tricks On You** — the "chef's signature" menu effect
4. **Food Is Connected To Memories** — home cooking, birthday cake, family meal, tea/coffee
5. **So… Who Is Actually Choosing?** — See + Expect + Remember + Read = What We Choose

## Note on imagery
The food visuals are original flat-vector illustrations generated by the build
scripts (no external/stock photos are embedded). To use your own photographs
instead, open the deck in PowerPoint and replace any illustration: right-click →
**Change Picture**, or delete it and **Insert → Pictures**.

## Rebuilding
```bash
npm install pptxgenjs sharp   # if not already installed
node raster.js                # render illustrations -> img/*.png
node build.js                 # assemble Psychology_of_Food_Choices.pptx
node preview.js               # optional: layout preview images for QA
```

## Files
- `art.js` — SVG food illustrations
- `raster.js` — rasterizes illustrations to `img/*.png`
- `build.js` — assembles the .pptx with pptxgenjs
- `preview.js` — renders approximate slide previews for visual QA
